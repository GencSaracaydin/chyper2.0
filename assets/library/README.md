# Asset library

Building blocks for the hypercasual games: characters, genre kits, icons, backgrounds, particles, UI, fonts, sound effects, and music. Every pack is licensed **CC0 1.0** (public domain), so it's free for commercial use with no attribution required. Most packs come from [Kenney](https://kenney.nl). Extra sound effects and music come from CC0 uploads on [OpenGameArt](https://opengameart.org), and each of those pack descriptions below names its author. Every pack folder has a `License.txt`: Kenney's original, or a note naming the OpenGameArt author and source page.

Packs whose authors ask for credit, or whose license isn't CC0 (for example CC-BY), are left out on purpose, because games published by users can't reliably carry credits.

## Layout

```
assets/library/
  manifest.json          every pack with source, author, license, and each file's path (PNG width/height included)
  <category>/<pack>/     curated files; Preview.png (where the pack has one) shows the whole pack
```

Categories: `characters`, `kits` (genre starter sets), `icons`, `environment`, `effects`, `textures`, `ui`, `audio` (sound effects and voice), `music`.

To keep the library small, only one resolution of each image is kept (Kenney's default size, not the Double/Retina/HD/Large copies). Vector sources, packed spritesheets, engine project files, and a few heavy texture variants are left out. The originals are one download away at each pack's source URL.

## Using these in games

Games run in a sandboxed WebView whose content security policy blocks all network access, so a game can't load these files by URL. To use one, inline it into the game HTML as a `data:` URI (base64) and decode it into an `Image` or `AudioBuffer`. The environment doesn't do that yet.

Audio formats: Kenney packs and most OpenGameArt packs ship Ogg Vorbis (`.ogg`). Packs that were originally WAV were converted to AAC (`.m4a`), which plays everywhere on iOS. Check that Ogg plays in the iOS WebView before relying on it. If it doesn't, convert with `afconvert -f m4af -d aac in.wav out.m4a` from the WAV originals, or with ffmpeg.

## Adding packs

Only add CC0 packs. For Kenney, download from `https://kenney.nl/assets/<pack>` and copy the default-resolution PNGs or audio plus `License.txt` into `<category>/<pack>/`. For OpenGameArt, check that the page's license field says CC0 and that the bundled readme doesn't ask for credit. Then add a `License.txt` naming the author and source page, and add the pack to `manifest.json`.
